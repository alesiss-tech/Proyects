¿Qué es Tinkercad?

Tinkercad es una herramienta en línea que permite realizar diseños en 3D y crear circuitos electrónicos de manera sencilla. Es ideal para aprender y experimentar con la tecnología.

NUESTRO DISEÑO 3D
Para realizar nuestro proyecto primero pensamos qué objeto queríamos crear.
Después comenzamos a utilizar las diferentes formas disponibles en Tinkercad.
Fuimos cambiando sus tamaños, posiciones y formas hasta conseguir el diseño final.
Durante el proceso tuvimos que prestar atención a las medidas y a la ubicación de cada parte para que el modelo quedara correctamente armado.
El resultado fue un modelo 3D que puede utilizarse como base para una futura impresión mediante una impresora 3D.
