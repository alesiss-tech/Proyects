¿Qué es App Inventor?

App Inventor es una herramienta que permite crear aplicaciones para dispositivos móviles mediante un sistema visual de bloques, de forma sencilla y sin necesidad de conocimientos avanzados de programación.

QUE ES UN MEMOGRAMA?
El memograma es un juego que consiste en encontrar parejas de cartas que tienen imágenes iguales. Generalmente, las cartas se colocan boca abajo para que los jugadores no puedan ver las imágenes. Por eso, es necesario recordar dónde se encuentra cada una para encontrar su pareja. Este juego combina la diversión con el ejercicio de habilidades como la memoria visual, la atención, la concentración y la asociación de imágenes. Existen diferentes versiones de memoramas, que pueden utilizar dibujos, animales, objetos, alimentos, letras o números.

COMO SE JUEGA?
Para jugar a Memograma, se siguen estos pasos: 1. Se toca una carta para descubrir su imagen.
2. Se toca una segunda carta para intentar encontrar la pareja.
3. Se comparan las dos imágenes.
4. Si son iguales, se encuentra una pareja.
5. Si son diferentes, las cartas vuelven a ocultarse.
6. Se continúa jugando hasta encontrar las parejas del nivel.
El objetivo principal es recordar las imágenes que aparecen y sus ubicaciones para encontrar todas las parejas.
