¿Qué es Arduino?

Arduino es una plataforma de hardware y software utilizada para crear proyectos electrónicos y sistemas programables. Permite controlar sensores, luces, motores y muchos dispositivos más.

¿ De que trata el proyecto?

Proyecto: Zapatilla inteligente con Arduino Nuestro proyecto consiste en el desarrollo de una zapatilla inteligente capaz de detectar obstáculos mediante un sensor ultrasónico y emitir una señal sonora de advertencia.
La idea surgió a partir de la necesidad de utilizar la tecnología para crear una herramienta que pueda servir como apoyo para personas con discapacidad visual. El sistema permite detectar si existe un objeto delante de la persona y avisarle mediante un buzzer.
Para desarrollar el proyecto utilizamos Arduino Uno y Tinkercad, una plataforma que permite simular circuitos electrónicos y probar programas antes de construirlos físicamente.
El funcionamiento de la zapatilla se basa principalmente en un sensor ultrasónico HC-SR04.
Este sensor se coloca en la parte delantera de la zapatilla y permite detectar objetos que se encuentran delante de ella. Para hacerlo, envía una señal ultrasónica y mide el tiempo que tarda en regresar después de rebotar contra un objeto.
Arduino recibe esa información y calcula aproximadamente la distancia a la que se encuentra el obstáculo.
Dependiendo de esa distancia, el programa puede hacer que el buzzer emita diferentes señales sonoras. De esta manera, cuanto más cerca se encuentra el obstáculo, más rápida puede ser la advertencia.
El circuito fue realizado inicialmente como una simulación en Tinkercad para comprobar que las conexiones y el programa funcionaran correctamente.

que componentes usamos?

Para realizar el proyecto utilizamos:
Arduino Uno: es el controlador principal del circuito. Recibe la información del sensor y ejecuta el programa.
Sensor ultrasónico HC-SR04: detecta los obstáculos y permite calcular su distancia.
Buzzer: produce las señales sonoras de advertencia.
Protoboard: permite realizar las conexiones electrónicas sin necesidad de soldar.
Cables jumper: permiten conectar los diferentes componentes.

Resistencia y LED: fueron considerados dentro de la propuesta inicial como indicadores adicionales del sistema, aunque la versión funcional que terminamos probando se centró en el sensor y el buzzer.

Cómo se realizo?

El proyecto se realizó paso a paso en Tinkercad.

Primer paso: seleccionar los componentes

Primero identificamos los componentes que íbamos a utilizar y los colocamos dentro del espacio de trabajo de Tinkercad.
Uno de los objetivos fue trabajar solamente con los materiales disponibles y evitar agregar componentes innecesarios.

Segundo paso: conectar Arduino y la protoboard

Comenzamos conectando el Arduino Uno con la protoboard, utilizando el pin de 5V para proporcionar alimentación y un pin GND para establecer la conexión a tierra.

Esto permitió utilizar los rieles de alimentación de la protoboard para conectar posteriormente los demás componentes.

Tercer paso: conectar el sensor ultrasónico

Después incorporamos el sensor ultrasónico.

En un principio hubo una confusión sobre el modelo del sensor, ya que se consideró la posibilidad de que fuera un sensor de tres pines. Al revisar mejor el componente utilizado en Tinkercad, comprobamos que el sensor utilizado en el circuito final tenía las conexiones correspondientes al HC-SR04, con alimentación, tierra, TRIG y ECHO.

Las conexiones quedaron organizadas de esta manera:

Sensor HC-SR04 Arduino
VCC 5V
GND GND
TRIG Pin digital 9
ECHO Pin digital 10
Cuarto paso: conectar el buzzer

Luego agregamos el buzzer para que pudiera funcionar como sistema de advertencia.
El Arduino controla el buzzer mediante uno de sus pines digitales. Cuando el programa determina que existe un obstáculo dentro de determinada distancia, genera un sonido.

Quinto paso: realizar la programación

Una vez realizadas las conexiones, comenzamos a programar Arduino desde el apartado Código de Tinkercad.

El programa se encarga de:

1. Activar el sensor.
2. Enviar una señal mediante TRIG.
3. Recibir la respuesta mediante ECHO.
4. Medir el tiempo que tarda la señal en regresar.
5. Calcular la distancia.
6. Comparar la distancia obtenida.
7. Activar el buzzer según la situación.
Una parte fundamental del programa es el cálculo de la distancia:
distancia = duracion * 0.034 / 2;
Esto permite transformar el tiempo medido por el sensor en una distancia aproximada en centímetros.
